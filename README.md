🚀 MentorOnDemand
📌 Overview

MentorOnDemand is a full stack web application designed to connect mentees with mentors based on skills, domains, and areas of expertise. The platform enables users to discover mentors, manage profiles, and interact through a scalable backend system.

The application follows a clean separation between frontend and backend layers, making it maintainable, extensible, and aligned with real-world enterprise development practices.

✨ Features

User registration and authentication for mentors and mentees

Mentor profile creation and profile management

Mentor discovery and search based on skills and domains

REST API based communication between frontend and backend

Modular and extensible application structure

🏗️ Architecture

Frontend and backend developed as independent modules

Backend implemented using layered architecture

RESTful APIs exposed for frontend integration

Design suitable for future scaling and microservices adoption

🛠️ Technologies Used

Java, Spring Boot, Spring MVC, Hibernate, JPA, RESTful Web Services, Angular, JavaScript, HTML, CSS, Relational Databases, Maven, Git

🎯 Use Cases

Mentees can browse and discover mentors based on skills

Mentors can manage their profiles and information

Backend services handle business logic and data persistence

Frontend provides a responsive and interactive user experience
